# Instructions for coding agents

Before every task, read `PROJECT_CORE.md` completely. It is the project constitution and source of truth for scope, architecture intent, design principles, and honest status.

Then inspect the current repository, Git status, README, and relevant methodology/report documents before editing. Do not assume planned features are implemented.

Current milestone: **Phase 1 — Dashboard Foundation only.**

Follow the scope, design direction, data-integrity rules, and definition of done in `PROJECT_CORE.md`. Do not over-engineer, scaffold the entire future platform, or install future security infrastructure during Phase 1. Preserve existing research and planning assets. Do not claim an integration, test, security control, or experiment is complete unless it has been implemented and verified.

At the end, report changed files, working features, tests actually run, demo-only areas, blockers, and the next smallest useful step. Do not automatically commit, push, or deploy.
